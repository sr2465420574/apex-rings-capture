# Apex Rings Capture

**简体中文** | [English](README.en.md)

在现有浏览器中，将 Apex Legends Status 的比赛交互回放保存为多阶段圈型地图截图，帮助 Apex 玩家进行非商业猜圈学习和比赛复盘。

## 能做什么

- 从赛事列表收集并去重 `Open interactive replay` 链接。
- 逐场打开回放，等待底图和多个阶段的圈线出现，核对显示设置及画面稳定性。
- 隐藏玩家信息及部分叠加元素，仅保存完整地图范围，输出 1024 × 1024 PNG。
- 保存比赛索引 CSV，支持当前列表及多个后续列表的断点续跑。
- 普通失败有限重试；验证超时、登录要求及明确权限限制会暂停。
- 批量任务提供独立控制窗口和有限次数的后台恢复；可选保持电脑与屏幕唤醒。

本工具保存的是网页已记录的多阶段圈型，并非只保存最终圈。它不保证网页记录覆盖所有阶段，不提取精确圆心、半径或原始回放接口数据。

## 运行要求

- 桌面版 Microsoft Edge（Chromium）；其他 Chromium 浏览器可自行验证，不承诺兼容。
- 能通过正常浏览器访问赛事列表及相应回放。
- 保持比赛窗口和控制窗口可见，原比赛标签页在其窗口中处于活动状态。
- 安装和采集不需要 Python、Anaconda、Node.js 或任何第三方包。Node.js 仅用于开发测试。

网站的访问规则与内容权利独立于代码许可证。请先阅读 [免责声明与内容权利](DISCLAIMER.md) 和 [安全与隐私声明](SECURITY.md)。

## 安装

1. 下载本仓库 ZIP 并解压到一个固定文件夹；不要直接从压缩包运行。
2. 在 Edge 地址栏输入 `edge://extensions/`。
3. 开启“开发人员模式”，点击“加载解压缩的扩展”。
4. 选择**直接包含 `manifest.json` 的文件夹**。
5. 在扩展菜单中找到“Apex 圈型截图（当前浏览器）”，可将其固定到工具栏。

这是通过源码手动加载的扩展，未声称已通过浏览器应用商店审查。安装前可以直接查看源码。

## 先采集一场样例

1. 用日常浏览器打开一个赛事列表，例如：

   <https://apexlegendsstatus.com/algs/Y6-Split2/Pro-League/APAC_S/Overview#tab_replaysandbans>

2. 确认网页可以正常访问，在该标签页点击扩展图标，打开独立控制窗口。
3. 点击 **“1. 收集当前列表”**，等待收集完成并核对场数。
4. 点击 **“2. 采集第一场”**。扩展会在原标签页打开回放并设置显示选项。
5. 等待下载完成，检查图片是否包含完整底图、多阶段圈线，且玩家标签等遮挡已隐藏。
6. 样例正确后，勾选确认框，再点击 **“3. 批量续跑（含后续列表）”**。

采集期间不要关闭原标签页、切走该窗口的活动标签、滚动或缩放地图。请只运行一个采集控制窗口，避免任务争用。

### 自动设置的选项

| 选项 | 目标设置 |
| --- | --- |
| 玩家信息 | `All players hidden` |
| `Next ring` | 开启 |
| `All rings` | 开启 |
| `Care packages` | 关闭 |
| `Respawn beacons` | 关闭 |
| `Heatmap` | 关闭 |
| `Pathing` | 关闭 |
| 其他下拉菜单 | 保留网页原值 |

加载过程中会重复核对设置；截图前再次只读检查。无法唯一定位控件时记录失败，避免猜测并点击其他选项。

## 连续处理多个赛事列表

在“当前列表完成后，依次采集这些赛事列表”文本框中，每行输入一个列表网址。例如：

```text
https://apexlegendsstatus.com/algs/Y6-Split2/Pro-League/NA/Overview#tab_replaysandbans
https://apexlegendsstatus.com/algs/Y6-Split2/Pro-League/EMEA/Overview#tab_replaysandbans
```

当前列表会先处理，随后按顺序切换；重复网址自动去重。留空则只处理当前列表。后续列表沿用已确认的样例设置，不需要逐列表确认。

仅接受与原网页同源的 HTTPS Apex Legends Status `Overview` 列表，不扩大到其他域名。赛季、阶段或赛区可以更改，具体页面结构仍需兼容。

## 输出文件

所有文件下载到**浏览器当前下载目录**下，不由扩展安装位置决定：

```text
ApexRings/
├── images/
│   └── 比赛名称__回放网址标识.png
├── index_赛事与赛区_网址标识.csv
└── diagnostics/                # 仅主动开启失败诊断后可能生成
    └── 回放网址标识.json
```

文件名中的短标识由回放或赛事列表网址生成，用于减少重名。它不等同于网站原始比赛 ID。

CSV 使用 UTF-8 BOM 编码，字段顺序如下：

| 字段 | 含义 |
| --- | --- |
| `id` | 回放网址生成的短标识 |
| `name` | 比赛名称 |
| `map` | 从比赛名称识别的地图；无法识别时为空 |
| `url` | 回放链接 |
| `image` | 相对浏览器下载目录的图片路径 |
| `status` | `pending`、`running`、`success`、`failed` 或 `paused` |
| `attempts` | 累计尝试次数，续跑后可能超过 3 |
| `rings` | 检测到的圈线 SVG 元素数，**不等同于权威圈阶段数** |
| `error` | 最近一次错误信息 |

当前列表处理结束后自动导出 CSV，也可点击“导出当前列表 CSV”。同一路径下载采用覆盖策略；需要保留历史版本时请先自行备份。

若浏览器开启“每次下载前询问保存位置”，下载可能等待保存对话框。扩展不会更改该设置。

## 暂停、重试与断点续跑

- 每场普通失败在单次处理流程中最多尝试 3 次；每次重试重新打开本场回放并重新检查后截图。
- 普通重试间隔约 8 秒、16 秒；比赛之间额外等待约 8～10 秒，不支持并发采集。
- 队列、成功记录、跨列表计划和偏好保存在扩展的 `storage.local` 中。
- 暂停后点击“批量续跑”可恢复同一已确认计划，跳过已成功记录。
- 不要通过重新“收集当前列表”恢复原计划：这会更新队列，并要求重新确认样例。
- 关闭控制窗口后，可以在同源赛事网页重新点击扩展图标，恢复本地已保存状态。
- 卸载扩展、清除扩展存储或使用另一浏览器配置会丢失本地断点；CSV 不是断点导入文件。
- 不会自动确认成功图片后来是否被移动或删除。

### 网站验证与访问限制

发现自动验证提示时，仅被动等待；默认最多 90 秒，可设置为 5～600 秒。验证等待时间不占用地图检查的约两分钟预算。

扩展不会点击人机验证、解答挑战、读取或注入 Cookie、伪装浏览器身份或绕过登录及付费限制。验证超时或网页要求登录、拒绝访问时暂停；需要人工处理的验证应由使用者在正常网页完成。反复遇到限制时，应停止采集并向网站咨询许可。

### 控制窗口无响应

批量采集时，控制窗口每 15 秒向后台发送心跳，后台约每分钟检查一次。连续至少 120 秒未收到心跳时，尝试重载控制窗口并从已保存计划恢复；浏览器调度可能延迟，不保证固定恢复时限。

10 分钟内最多自动恢复 3 次。手动暂停、关闭原标签页或控制窗口、验证超时及明确访问限制不应触发普通卡顿恢复。样例和收集列表操作不自动恢复。

可选“保持电脑和屏幕唤醒”需要单独授权 `power` 权限，仅在任务期间请求保持唤醒，不修改系统永久电源设置。不能阻止手动休眠、关机或所有合盖行为；电脑已经休眠时无法继续截图，后台定时器也无法唤醒电脑。

## 限制与验证范围

目前适配唯一可见的 Leaflet 地图容器、完整图片底图和白色 SVG 圈线。需要底图完整可见、至少检测到两个圈线元素，且连续截图稳定至少 3 秒。

以下情况可能失败：网站结构或控件变化、Canvas 或瓦片渲染、缺少历史数据、其他叠加元素持续动画、浏览器缩放或窗口过小、标签页冻结和网站访问限制。

1024 × 1024 只统一图片尺寸，不保证不同地图的地理比例一致。成功状态也不能替代人工检查圈线完整性。

已有本地自动化测试覆盖来源边界、裁切、显示设置、验证等待、队列、有限重试相关基础逻辑及后台恢复；包含虚拟时间模拟，**不能替代真实浏览器长时间无人值守测试**。不承诺在所有赛季、地图和浏览器中可用。
